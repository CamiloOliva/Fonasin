# Base de datos

Este directorio alojara las migraciones y seeders Laravel cuando se inicialice el backend.

La estructura funcional propuesta, reglas de almacenamiento de datos sensibles y auditoria estan documentadas en:

- `docs/architecture/data-model.md`
- `docs/architecture/audit.md`

No se debe crear una migracion sin actualizar esos documentos cuando cambie una entidad, relacion, estado o regla de retencion.
